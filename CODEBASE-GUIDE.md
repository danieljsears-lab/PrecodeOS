## Risk-Triggered Production-Readiness Guidance

Use this section only when an approved PRD identifies durable module-placement, shared-boundary, ownership, naming, or repository-convention risk. Record where the code belongs, what owns the behavior, which local convention governs it, and which boundaries must remain stable. Do not introduce a new architecture for one-off low-risk work or treat tidy placement as production-readiness certification.
